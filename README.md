# Lindor & Zeynab — Invitation au mariage

Invitation numérique (une seule page `index.html`, sans serveur), hébergée sur GitHub Pages.

- Lien invité personnel : `…/#i-<places>-<événements>-<nom>` (généré depuis l'espace des mariés).
- Espace des mariés : `…/#organisateurs` (génère les liens + messages WhatsApp / e-mail).
- Réponses (RSVP) : envoyées aux mariés par WhatsApp ou e-mail.
- Tout se règle dans l'objet `CONFIG` en haut du script : dates, lieux, infos, numéro WhatsApp, son (`audio.mp3`).
